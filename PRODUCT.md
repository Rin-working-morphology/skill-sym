## Design Context

### Users
SkillSym is for developers and heavy AI coding users who maintain reusable skills across global and project-level tool folders. They need to configure local workspaces, publish skills into Claude, Codex, Qoder, and similar folder conventions, and verify whether reusable skill files are correctly linked or copied.

### Brand Personality
Calm, precise, work-focused. The interface should feel like a quiet desktop management tool that gives users confidence about installed content, file locations, and the next operation.

### Aesthetic Direction
Minimal product UI with black, white, and neutral gray as the main vocabulary, plus very limited accent color. Avoid dirty greens, decorative gradients, visible texture, heavy shadows, crowded cards, and attention-seeking motion. Structure should come from grid, baseline rhythm, fine separators, and clear typographic hierarchy.

### Design Principles
- Put content first: skill names, workspace scope, source location, and publish state must be faster to read than surrounding controls.
- Keep low-frequency actions quiet: workspace base editing and removal belong in contextual controls, not the main working surface.
- Use restrained feedback: hover and active states should rely on subtle border, text, and background changes.
- Prefer layout order over decoration: fine lines, white space, and consistent columns carry the interface.
- Preserve operational clarity: the user should always understand the selected scope, current base directory, publish mode, and available targets.
